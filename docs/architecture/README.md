# Architecture

KMJ Forge is designed around a small orchestration core and modular capabilities.

High-level layers:

1. **Experience** — CLI, desktop, IDE, optional web.
2. **Intelligence** — repository intelligence, context, planning, model routing, memory, skills.
3. **Execution** — filesystem, terminal, Git, sandbox, browser, containers/VMs.
4. **Verification** — build, tests, review, security, performance.
5. **Governance** — permissions, policy, audit, approvals, rollback.
6. **Ecosystem** — adapters, tools, skills, plugins.

The master roadmap remains the authoritative strategic reference during bootstrap.
